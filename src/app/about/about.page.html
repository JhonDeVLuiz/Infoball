Trabalho OAT - Desenvolvimento Mobile

Este aplicativo foi desenvolvido por Jhon Luiz como parte do Trabalho OAT da disciplina de Desenvolvimento Mobile. Utilizando o framework Ionic, o projeto tem como objetivo explorar os conceitos fundamentais de criação de interfaces móveis híbridas, integração com componentes nativos e boas práticas de usabilidade.
