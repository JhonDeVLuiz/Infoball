Trabalho OAT - Desenvolvimento Mobile

Este aplicativo foi desenvolvido por Anderson como parte do Trabalho OAT da disciplina de Desenvolvimento Mobile. Utilizando o framework Ionic, o projeto tem como objetivo explorar os conceitos fundamentais de criação de interfaces móveis híbridas, integração com componentes nativos e boas práticas de usabilidade.

A proposta do trabalho inclui a construção de páginas funcionais, navegação entre telas, uso de componentes do Ionic Framework e aplicação de estilos personalizados. Este projeto representa uma etapa importante na formação técnica de Anderson, demonstrando sua capacidade de aplicar conhecimentos teóricos em uma solução prática e interativa.
